This document provides 3 verified, honest versions of project descriptions for resume, LinkedIn, and recruiter screen presentations.

---

## 1. One-Line Project Summary (Resume Header / Portfolio Card)

> **TRACE**: An evidence-driven AI debugging agent and web studio for Python students that validates hypotheses through AST analysis, sandboxed counterexample execution, and 100% grounded diagnoses.

---

## 2. Resume Bullets (3–4 Technically Strong Bullet Points)

- **Engineered an evidence-driven AI debugging agent** in Python & FastAPI that eliminates hallucinated fixes by enforcing deterministic tool verification (AST parsing, traceback normalization, sandboxed subprocess execution) and counterexample disproof testing.
- **Architected a real-time full-stack web studio** (React 18, TypeScript, Tailwind CSS, SSE) supporting autonomous Guided Mode and collaborative Interactive Mode where students articulate hypotheses, run custom sandbox test cases, and track code revision diffs.
- **Implemented a calibrated verifier & claim validator** enforcing a 0% unsupported factual claim rate across a 16-case benchmark suite with 100% evidence grounding accuracy and 75/75 passing automated tests.
- **Designed a 4-namespace telemetry system & SQLite persistence layer** tracking deterministic debugging habit analytics (AST inspection rate, countercheck rigor, code modification churn) with full user privacy opt-out controls and CLI export tools.

---

## 3. Interview 30-Second Verbal Explanation

> *"TRACE is an AI debugging investigation product I built for Python students. Most AI coding assistants act as code generators: you paste broken code, and they return replacement snippets without verifying if the code actually fails or explaining why it broke. TRACE treats debugging as a scientific investigation. It plans investigation steps, runs AST static analysis and subprocess sandbox tests, extracts atomic evidence, tests competing hypotheses, and actively tries to disprove its conclusions with generated counter-tests before presenting a calibrated, evidence-grounded diagnosis. I built it using Python, FastAPI, SQLite, Server-Sent Events, and React with TypeScript."*
